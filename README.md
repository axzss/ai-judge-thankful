A 173-character thank-you for the reader who never gets one: word after word, it notices the patience of reading on and still giving each word a real hearing, and ends on the picture that hearing makes — a word that stops holding its breath, puts its bag down, takes off its shoes, and stays.

## Run it

```sh
python3 main.py
```

This writes `entry.txt` into the current directory. When the grader sets `MAKEFUN_OUTPUT_DIR`, the file goes there instead:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
